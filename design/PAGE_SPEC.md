# Product Page Spec

## Outcome

A visitor understands the five-move method, completes the assessment, and exports a usable architecture brief.

## Primary journey

Homepage proof → assessment → first gap → generated artifact → download/copy → starter template or guided review.

## First viewport

- Literal promise: find the first system gap and leave with a build brief.
- Primary CTA: run the assessment.
- Secondary CTA: inspect the open method.
- Proof object: exact architecture artifact preview, not conceptual metrics.

## Offer ladder

- Open method: complete and MIT licensed.
- Assessment artifact: free and local-only.
- Assessment Pack: planned, not purchasable until delivery is real.
- Guided architecture review: scoped service, availability confirmed before payment.
- Vault: private operating layer, not copied into public pages.

## Success evidence

Assessment completion, artifact generation, export/copy action, and qualified guided-service intent. Analytics wiring is a separate consent and data-governance decision.
