# Spatial Intelligence Program — proposed extension, 2026-11-25

## PRD
Imagine it. Build it. Witness it. Extend existing Reality Studio (Today, Atlas, Bridges, Witness, Map, Timeline, Soul) with Garden, Stellar graph, vision scenes and optional walkable worlds. Initial audience: AI-native creators and knowledge workers who want durable personal intelligence. First value: import or author a vision, plant a seed, choose an action, record evidence and see the same entity in Markdown, graph and garden. Preserve Meaning / Mechanism / Limits and reported / verified / desired / hypothesis / planned / done distinctions. No causal manifestation or outcome promises.

## Architecture
Keep reality.md v0.2, soul.md and reality/ as portable person-owned contracts; extend with versioned world manifests, stable entity IDs, typed edges, evidence events, asset references and placement overrides. Define explicit sync authority, revision hashes, conflict resolution, offline queue, idempotency and export/import round-trip. Local-first default; optional owner-hosted PostgreSQL/pgvector and Supabase RLS/Auth, private R2 or equivalent object storage, scoped MCP OAuth and local stdio. Hosted managed memory is a proposed change to existing local-only doctrine, not approved by this document. Never publish live vaults. Public worlds are allowlisted, sanitized immutable projections with independent asset permissions, preview, explicit publish, revoke and cache invalidation. No private edges, embeddings, metadata or signed private URLs in public output.
World compiler: deterministic entity-to-scene projection, versioned asset manifest, stable placement, evidence-derived growth, historical replay, user override. React Three Fiber/Three.js/Drei, glTF/KTX2/Meshopt, Blender procedural geometry; Sigma/Graphology for large graphs; accessible HTML fallback. Evaluate Rapier, navmesh, WebXR, A-Frame, Babylon, Hubs community forks and spatial collaboration (later); no premature multiplayer dependency. MCP resources expose authorized entities and world manifests; tools propose/plant/connect/log/inspect/export/publish with approval for publication and contract edits. Preserve READ/SURFACE/PROPOSE/LOG/GUARD. Treat retrieved documents as untrusted data.

Existing MIT rights remain intact. Paid hypotheses: €29–79 premium world packs, €99–199 creator toolkit, €15–29/mo optional managed sync/intelligence after approval and cost validation. No paywall on data export or basic privacy. No checkout until delivery, license, price and refund gates pass.
## Roadmap and acceptance
R0 inventory existing code/PRs/designs and lock contracts. R1 local seed→action→evidence→garden vertical slice, fresh install and reload, no account required. R2 opt-in private sync, agent integration, graph/timeline, backup/restore, cross-tenant negative tests. R3 sanitized shareable world, creator pack SDK, premium asset pipeline, checkout sandbox and entitlement tests. R4 walkable avatar sanctuary, spatial audio, optional XR and later multiplayer. Each release requires draft PR, reproducible test commands, screenshots, preview URL, accessibility and performance report, security review, rollback and human production approval.
Proposed targets: first value within 5 minutes for 8/10 usability participants; 100% round-trip of supported fields; zero cross-tenant/public leakage in adversarial tests; p75 LCP <=2.5s for non-3D shell, initial compressed scene <=5MB, >=30fps on named midrange mobile and >=60fps target desktop, measured on actual devices; WCAG 2.2 AA for core HTML flows. Pilot: 20 users, measure first-value completion, 7-day meaningful evidence retention, qualitative usefulness, paid conversion and cost per active user; targets are hypotheses, not observed results.
