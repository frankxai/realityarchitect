# The Imaginal Act

Status: implemented on the Threshold review branch; production publication remains gated. Built on SIP.

The experience serves the founder's October 4 request for felt fulfillment, original art and poetry, and a bridge from inward imagination into a physical act. It evolves the existing Threshold proposal in PR #38. It does not replace the five-move technical method or import private personal context.

## Experience

`/threshold` opens with an original sea-and-stone scene and the invitation “Let it feel like home.” An original poem, “Before the key,” introduces a restrained contemplative passage. The visitor authors one scene and optional chosen giving. Rest mode removes the fields and allows an unhurried reading of their own scene; returning preserves the draft. The action path contrasts the scene with a reported present fact and an anticipated obstacle, then requires a next act, timing, and evidence criterion. Markdown and versioned JSON exports are explicit user actions.

The desired state is not an observation. A reported fact is not independently verified. A planned act is not completed. JSON consent defaults to false for AI, cloud sync, and sharing. No service is connected to these exports automatically. Page memory clears on leaving or refreshing; no app persistence or content telemetry is added. Ordinary hosting request metadata still exists.

## Evidence boundary

Spiritual language describes a contemplative lens, not an empirical result. The interface makes no promise of manifestation, clinical effectiveness, wealth, or another person's behavior. Its intended mechanism is authorship plus rehearsal and a specific action plan; whether this implementation helps users act remains untested.

The randomized study by Duckworth et al., *From Fantasy to Action* (2013, published online 2014), supports the distinction between positive imagery alone and mental contrasting with implementation intentions in its school population. It does not establish efficacy for this website or prove a metaphysical law. Source: https://pmc.ncbi.nlm.nih.gov/articles/PMC4106484/ . Quantum physics is not used as evidence that personal desire controls external events.
