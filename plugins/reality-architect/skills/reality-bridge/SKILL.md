# Build or check a Bridge

A Bridge is one aim, written as `reality/aims/<slug>.md` (format: standard/STATE.md). It connects the person's
**desired** scene to what is **reported** true now, through **planned** acts.

## Build (interview, one question at a time)

1. **Aim** and **done when** (something an outsider could verify) and **by** (a date).
2. **The scene (desired):** an ordinary moment when it is done, in the present tense.
3. **True now (reported):** one specific fact.
4. **Obstacle:** the first inner or outer obstacle; classify its gap class: knowledge, capability, resource,
   coordination, technology, permission, process, evidence, or time. Then the if-then: "If <obstacle>, then I <act>."
   (Mental contrasting with implementation intentions: the studied pairing.)
5. **Skills to grow** (human), and **systems to build** (AI workflows), each tagged with its Architect's Loop move: See
   (memory), Design (spec), Build (one agent), Automate (supervised loop), Compound (outcome signal). Recommend only the
   first move they have not locked in.
6. **Reps:** recurring practice with a weekly count, small enough to keep.
7. **Bold moves:** one-off acts with dates. This is where "massive action" lives, made concrete.
8. **People and places:** who they need to meet, which environments to enter, each with why.

Write the file after showing it.

## Check: "Is it enough?"

Use the last 14 days, or since the bridge started. Planned reps = sum of weekly counts × days ÷ 7. Logged reps = `rep`
entries for this aim in `witness.md` within the window. Overdue moves = not done and due before today (due today is not
overdue).

| Condition | Answer |
| --- | --- |
| no reps and no moves | Not enough yet: nothing is defined to do. Add one rep for this week. |
| the date has passed | Review it: achieved, extend, or release. |
| started under 3 days ago, nothing logged | Too early to judge. Log the first rep. |
| ratio ≥ 0.8 and nothing overdue | On pace. |
| ratio ≥ 0.5, or one move overdue | Behind. Shrink the rep or move a date; do not add pressure. |
| otherwise | Not enough for the date. Make the rep smaller, change the environment, ask someone, or extend. |

Always show the numbers you used. Suggest **one** change, the smallest that would move the verdict.

## Never

- Never promise the aim will happen. Never call a slow week a character flaw.
- Never design a move that depends on controlling another person's choice.
